# 发布范围与脱敏说明

公开包从最终课程工程另行整理，原始项目、学校提交文件和个人报告保留在本地。完整发布指的是游戏源码、依赖源码、地图、必要资源与复现说明；编译产物不是复现所需源码。

## 已排除

- 个人姓名、班级、学号和私人联系信息所在的课程报告。
- 原始聊天、对话截图、学校下载日志、录像、提交编号和时间记录。
- 含本机路径的 Qt Creator 用户配置、编辑器工作区文件和生成的 Makefile。
- exe、DLL、目标文件、自动生成的 UI/MOC 头文件及其他编译缓存。
- 密钥、环境变量文件和本地实验目录。

评测仅保留匿名样本号、胜负、帧数、分数和运行秒数。文档路径使用仓库相对路径或可替换安装示例，没有学生电脑的用户目录。新发布提交采用通用贡献者身份。

原框架作者、Perlin 噪声库作者等许可署名保留，这些不是学生个人信息。公开仓库的账户名和 URL 是仓库本身的公开身份，本次不会重写它或声称仓库所有者匿名。初始化历史保留，公开整理没有强制重写已有 Git 历史。

## 后续贡献也应保持

上传截图前检查账户、桌面路径和日志；提供故障案例时截取必要信息。个人报告、学校账号和可追踪提交记录留在私有目录。新增日志或脚本时用 `<项目目录>`、`<Qt目录>` 等参数，避免把个人环境硬编码进源码。

通用仓库校验脚本用于检查资源与文件结构，不能证明未知密钥或第三方二进制完全没有隐私；发布整理另外扫描已知个人标识、路径和资源文本。任何后续内容仍需根据实际情况检查。
