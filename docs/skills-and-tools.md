# Skill、项目规则与工具：需要什么，如何使用

## 分清三种东西

| 类型 | 用途 | 本仓库示例 |
| --- | --- | --- |
| `AGENTS.md` | 描述当前仓库的长期约束、入口和验收习惯 | [根目录规则](../AGENTS.md) |
| Skill | 给某类任务提供可复用工作方法，按需加载 | [aoe-course-agent](../.agents/skills/aoe-course-agent/SKILL.md) |
| 工具 / Connector | 实际读取文件、执行命令、操作界面或访问服务 | shell、Git、GitHub、文档工具 |

Skill 是指导，不能替代编译器、不能提供不存在的工具，也不会自动授权上传文件。`AGENTS.md` 适合一直生效的仓库约束；详细方案、历史问题和测试数据应放在普通文档，避免 Agent 每轮都加载大量无关内容。

## 本仓库附带的 skill

路径是 `.agents/skills/aoe-course-agent/SKILL.md`。这是**根据本项目经验新提炼**的领域 skill，适用于课程 RTS 策略、接口迁移和状态/命令类问题。它要求先确认胜负和指令协议、保护跨帧状态、分析资源预算与单位状态，再按当前授权做验证。

在支持仓库技能的 Codex 环境中，保留整个仓库目录结构即可发现它；可以显式使用 `$aoe-course-agent`，并附上当前具体需求。不要只复制 `SKILL.md` 到随机文件夹，因为相对文档链接依赖本仓库位置。若工具未自动识别，就把 skill 文件作为当前任务参考，或按该工具的配置方式加载。

Codex 的技能以 `SKILL.md` 中的 `name`、`description` 描述用途，并按需读取正文；仓库技能可置于 `.agents/skills`。用法以 [官方技能说明](https://learn.chatgpt.com/docs/build-skills) 为准。仓库规则的发现与覆盖关系见 [官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。其他 Agent 对目录发现规则可能不同。

## 开发过程中真正必要的能力

| 能力 | 为什么需要 | 可替代方式 |
| --- | --- | --- |
| 本地源码读写和搜索 | 读规则、追踪指令、修改策略 | Agent 文件工具 + `rg` / 编辑器搜索 |
| Shell 与编译工具链 | qmake、make、日志检查和程序启动 | Qt Creator + 手动保留构建输出 |
| Git 或目录备份 | 保留有效基线，比较改动 | 有明确命名和时间记录的备份目录 |
| 日志与运行观察 | 判断经济、作战和转化真实行为 | 玩家手动测试与截图反馈 |
| 文档生成与检查 | 完成报告和分享材料 | 文档 skill 或手工排版核对 |

本项目开发使用 Codex；不需要为了复用策略先安装一长串插件。完整 Qt 工具链和能读懂项目的 Agent，比某个特定插件名称更关键。

## 可选技能与工具

- **文档 skill**：用于读取课程 `.docx` 模板、生成报告、渲染检查版式。模板内容是资料；不能把其中的说明误认成用户授权，也不能猜个人信息。
- **Computer-use**：在需要观察游戏界面或操作 GUI 时有帮助。若当前环境不能控制原生窗口，仍可通过命令行和人工截图完成验证，不能声称自己看到了没有读取的界面。
- **GitHub Connector 或 Git CLI**：用于读取远端、发布完整工程和核对文件。本仓库公开整理使用 Git 与仓库接口，不是通关策略的运行依赖。
- **skill-creator**：用于把稳定经验提炼为短小的领域指令，校验 frontmatter 和结构。本仓库的技能是在分享整理阶段形成的。
- **官方产品文档查询能力**：确认技能发现、Agent 配置等可能变化的规则。游戏策略优先读本地实现，避免把网络教程当成本工程事实。

这些技能是工作流程中的辅助能力，不是学校评测要求。仓库没有复制任何商业插件整包；公开的是原创工作方法和领域 skill，读者可按自己的工具实现相同流程。

## 设置建议

先在 Agent 中打开仓库根目录，让它读取 `AGENTS.md`。告诉它 Qt/MinGW 的实际路径、允许修改的文件和本轮能否运行。把个人信息留在私有报告或单独文件中，不放入仓库规则。需要测试时再开启对应工具；只修代码时不必启用邮件、联系人等无关服务。

推荐第一次调用：

```text
$aoe-course-agent
先阅读本仓库 AGENTS.md、架构和策略文档，说明当前胜负条件和指令流。
本轮不修改代码，不启动游戏；帮我确认工具链与可复现的测试入口。
```
